**This file is a map, not the truth for every site.** Settings depend on the installed versions, the Theme Kit Pro modules that are on, and active integrations (WooCommerce, LearnDash, LifterLMS, Tutor LMS, The Events Calendar, bbPress add sections only when active). On a real site, run `scripts/customizer-schema.php` and trust its JSON over this file.

How to read a line: `key` · control type · label · default · choices (value = label). Value shapes per control type are in `customizer-automation.md` §3.
