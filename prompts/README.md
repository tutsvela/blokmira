# Sample prompts

Paste one of these into an agent that has Blokmira installed. Each prompt states what to build and the limits that matter, and asks for a plan before anything is written. Replace the bracketed parts.

| Prompt | What it shows |
|---|---|
| [Site audit](SITE_AUDIT.md) | Inventory, modules, overrides and what is possible before you plan |
| [Brand setup](BRAND_SETUP.md) | Palette, fonts, widths, header and footer as a validated Customizer change file |
| [Landing page](LANDING_PAGE.md) | A full landing page in native Kadence blocks, section by section |
| [Design to blocks](DESIGN_TO_BLOCKS.md) | One section from a screenshot or Figma frame, mapped control by control |
| [Header and footer](HEADER_FOOTER.md) | Header Builder, sticky and transparent header, footer rows, per-page footer |
